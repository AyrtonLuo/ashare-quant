## 1. Dataset Manifest Schema

Every historical dataset generated by the storage pipeline emits a mandatory `DatasetManifest` file:

```python
from dataclasses import dataclass
from typing import List, Dict

@dataclass(frozen=True)
class DatasetManifest:
    dataset_id: str           # e.g., "golden_ashare_daily_v1"
    created_at: str           # ISO timestamp "2026-08-02T00:00:00Z"
    primary_source: str       # "tushare_pro_primary"
    secondary_source: str     # "akshare_secondary"
    schema_version: str       # "1.0.0"
    start_date: str           # "2020-01-01"
    end_date: str             # "2026-08-01"
    symbol_count: int         # Number of symbols e.g., 20
    row_count: int            # Total row count
    checksum_sha256: str      # Cryptographic SHA-256 hash of dataset content
    validation_status: str    # "VERIFIED"
```

## 2. 100% Reproducibility Guarantee

If a dataset needs to be reconstructed 6 months later:
1. Re-query Primary Provider using `primary_source`, `start_date`, `end_date`, and `schema_version`.
2. Run Normalization Layer and `DataTrustGate`.
3. Compute SHA-256 checksum and verify against `checksum_sha256` in `DatasetManifest`.
4. If checksum differs (due to provider financial restatements), emit `DATASET_RESTATEMENT_DETECTED` audit alert.
